# Retail Sales Date Cleaning

## Project Overview
This project focuses on cleaning and standardizing date values in a Retail Sales Dataset using Google Sheets.

## Dataset
Retail Sales Dataset

## Work Completed
- Created Raw Data and Cleaned Data sheets.
- Standardized the date format to DD-MM-YYYY.
- Identified 2 missing dates.
- Kept missing dates blank for verification.
- Created an Issue Log to record data issues.
- Prepared a Date Cleaning Summary.

## Date Cleaning Summary
Total Records - 1002 
Valid Date Values - 1000 
Missing Dates - 2 
Missing Date Rows -1002, 1003 
Standard Date Format - DD-MM-YYYY 

## Tools Used
- Google Sheets

## Outcome
Successfully standardized the date format, identified missing dates, and documented the issues in an Issue Log.
